# Notinoty — 음악 협업 워크스페이스

> 최종본을 찾느라, 작업이 멈추지 않게.

**Notinoty** 는 작곡·편곡·보컬·엔지니어링 팀을 위한 음악 협업 SaaS 입니다.
`vocal_FINAL_v2_real.wav` 같은 파일명 버저닝과 단톡방에 흩어지는 "OK" 를,
트랙 단위 칸반·버전 히스토리·승인 기록으로 대체합니다.

**무료로 시작** (신용카드 불필요): https://notinoty.kr

## 핵심 기능

- **트랙별 칸반 보드** — 작업 전 → 작업 중 → 승인 대기 → 완료. 담당자·버전·상태가 한 화면에.
- **버전 히스토리** — 버전마다 메모·LUFS·승인자·날짜가 자동으로 쌓입니다.
- **승인 워크플로** — 누가 언제 승인/반려했는지 영구 기록. 반려 코멘트는 다음 버전에 연결.
- **모아듣기** — DAW 없이 브라우저에서 멀티트랙 동시 재생, 타임코드 핀 코멘트.
- **게스트 검토 링크** — 로그인 없이 클라이언트가 듣고 승인/반려.
- **발매 준비** — 음량·메타·크레딧 체크리스트로 발매 전 확인.
